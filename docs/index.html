创作顾问

密钥只存在你这台设备的浏览器里，不会上传到任何地方。
已实测 DeepSeek、Kimi、智谱、通义都允许浏览器直连。想零成本先试， 注册 open.bigmodel.cn 用 glm-4-flash；想长期用，DeepSeek 便宜且中文好。

自动同步

两台设备填成一模一样，改动就会自动同步过去。数据存在你自己的账号里，不经过任何第三方服务器。改动后约 5 秒推一次，后台每分钟拉一次。

打开 github.com/settings/tokens → Generate new token (classic) → 只勾选 gist → 生成后把那串 ghp_ 开头的复制进来。手机上同样填这两项。

同步码就是钥匙——知道它的人就能读写你的稿子，所以起长一点、别外传。

必须用系统浏览器打开这个网址，微信内置浏览器做不到。
安卓 Chrome：右上角 ⋮ → 看到「安装应用」才是对的；只看到「添加到主屏幕」说明还差一步，见下面的自检。
iPhone Safari：底部中间的分享按钮 → 往下滑 →「添加到主屏幕」。
